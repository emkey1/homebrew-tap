# emkey1's Homebrew tap

```sh
brew install --cask emkey1/tap/foray
```

| Cask | |
|---|---|
| [foray](Casks/foray.rb) | [Foray](https://github.com/emkey1/Foray), a file browser for macOS that does what Finder does, minus the parts that get in the way |

Foray also updates itself (Foray › Check for Updates…); `brew upgrade --cask foray` works too.
